## canvas-apps-react-ui

Uma skill pensada para transformar Power Apps Canvas em uma experiência visual mais sofisticada, organizada e próxima do modo como times React pensam interfaces.

### O que este projeto entrega

- Sistema de componentes documentado em markdown
- Design system com variáveis CSS completas
- Mapeamento claro entre hooks React e fórmulas Power Apps
- Exemplos práticos de dashboard, lista, detalhe e formulário
- Templates para novas telas e novos componentes
- Padrões de acessibilidade e responsividade já embutidos

### Para quem isso é útil

- Makers que querem padronizar Canvas Apps
- Times que precisam acelerar UI sem perder consistência
- Consultores Power Platform que querem uma base reutilizável
- Pessoas que pensam em React, mas precisam entregar dentro do Power Apps

### Destaques

| Área | Conteúdo |
|------|----------|
| Base visual | AppShell, Header, Card, Button, Input, Badge |
| Estado de UI | Loading, EmptyState, Modal, FormGroup |
| Layout | BottomNav, DataTable, grids responsivos |
| Arquitetura | Hooks, helpers, templates e screens |
| Exemplo real | Gestão de ordens de serviço end-to-end |

### O resultado esperado

Esse pacote não tenta simular React por marketing. Ele traduz a mentalidade de componentes, props e estados para a linguagem real do Power Apps, com um foco forte em manutenção e consistência visual.
